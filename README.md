# BetterEnderChest — Export Fork (разовый фикс)

> ⚠️ **Это любительский форк, созданный для решения одной конкретной проблемы.**
> Он не претендует на звание полноценного плагина, не поддерживается автором
> оригинального BetterEnderChest и, скорее всего, не будет обновляться.

## 🧩 Зачем это нужно

Оригинальный плагин **BetterEnderChest** не был обновлён для серверной версии **26.3**,
из-за чего стандартные способы миграции эндер-сундуков на ванильные перестали работать.
Администраторам, которым нужно было перенести данные и удалить плагин, приходилось
делать это вручную.

Этот форк добавляет **одну команду** и **один класс**, которые решают ровно эту задачу:
прямой перенос предметов из файлов BetterEnderChest в ванильные `playerdata` игроков,
включая офлайн-игроков.

## ✨ Что добавлено

| Файл | Назначение |
|---|---|
| `EnderChestToPlayerDataCommand.java` | Класс команды `/ecexport` |
| Регистрация в `plugin.yml` и `onEnable()` | Подключение команды |

Больше **ничего** не менялось. Весь остальной код — оригинальный BetterEnderChest.

## ⚙️ Как использовать

> **Перед началом обязательно сделайте резервную копию:**
> - папки `world/playerdata` (или `world/players/data` для Paper 26.3+)
> - папки `plugins/BetterEnderChest/`

1. Соберите форк (`./gradlew build`) и установите `.jar` на сервер.
2. Остановите сервер (команда `stop`) и убедитесь, что **все игроки вышли**.
   Если кто-то останется онлайн, сервер может перезаписать файлы своим кэшем.
3. Запустите сервер и выполните в консоли:
4. Дождитесь окончания работы команды. В консоли появится отчёт:
- сколько сундуков перенесено,
- сколько пропущено (нет файла `playerdata` — игрок никогда не заходил),
- сколько предметов отброшено (слот > 26, т.к. ванильный сундук вмещает только 27).
5. **Проверьте результат**: остановите сервер, временно переименуйте
`BetterEnderChest.jar` в `BetterEnderChest.jar.disabled`, запустите сервер,
зайдите игроком и откройте эндер-сундук. Если предметы на месте — можно удалять плагин.
6. После проверки удалите плагин и папку `plugins/BetterEnderChest/`.

## ⚠️ Важные ограничения

- **Команда копирует, а не перемещает** предметы. Данные в `chestData` остаются нетронутыми.
- **Ванильный эндер-сундук вмещает только 27 слотов.** Если у игрока в кастомном
сундуке было больше слотов, излишки будут **отброшены** (в консоль выведется
предупреждение с UUID и количеством).
- **Несколько world groups**: если в `chestData/<groupName>/` несколько папок,
команда обработает все. Для игрока с сундуками в разных группах победит тот,
что обработан последним.
- **Игроки без `playerdata`** (никогда не заходили на сервер) пропускаются —
переносить им некуда.
- Команда **не тестировалась** на всех возможных конфигурациях сервера.
Используйте на свой страх и риск, предварительно сделав бэкап.
